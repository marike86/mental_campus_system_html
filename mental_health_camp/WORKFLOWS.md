# 课程、审核与运营功能

## 启动与升级

在 `mental_health_camp` 目录执行：

```powershell
python -m pip install -r requirements.txt
# 停止 Web 服务和 worker 后执行；已有数据库会先备份。
python migrate.py --backup ./before-workflows.backup
uvicorn main:app --host 127.0.0.1 --port 8000
# 在独立进程中运行，或用服务管理器保持一个实例运行。
python worker.py
```

新数据库也需要先执行 `python migrate.py`。已有数据库迁移前检查重复报名、重复当天提交、重复每日表单和孤立关联，错误消息列出记录 ID，须修复后重试。不会自动删除冲突数据。迁移重复运行不会重复导入历史轮次或发送通知。

应用启动只接受匹配的数据库版本；禁止滚动混用旧版和新版服务。五个功能 PR 为依赖链，应在整条链合并、验证后统一部署。修改版本后请在副本上先演练迁移和恢复。

## 数据恢复演练

维护窗口停止全部服务，将数据库及迁移前备份复制到独立目录，记录当前 `DATABASE_URL`。在副本上设置 `DATABASE_URL=sqlite:///副本的绝对路径` 后运行迁移并验证。恢复时先停止服务，保留故障数据库，将迁移前备份复制到新的数据库文件，使用对应的旧版本应用并指向恢复文件，再检查学员、训练营和答案记录。不要让旧应用连接迁移后的数据库。

自动化迁移测试包含副本迁移、重复执行、备份恢复验证及损坏数据中止。仓库跟踪的示例数据库不会用于测试。

## 使用流程

- 管理员编辑每日表单时，保存只更新草稿。通过“预览已保存草稿”检查后，在“发布与版本历史”发布。历史内容可复制为草稿后重新发布。
- 学员打开课程入口后点击“开始学习”，此时锁定版本。第 N 天必须到计划日期并且前一天通过审核；允许计划结束后补交，管理员停用训练营后禁止开始和提交，但历史和已提交审核仍可访问。
- 新报名采用批次开始日期，没有批次日期时采用批准日期。已有开课日期不会因后续编辑批次而改变。
- 公共审核队列只展示任务摘要；审核员在容量内领取后查看答案。管理员可以直接审核、指定或转交。账号管理仍仅超级管理员可用。
- 驳回必须有批注。重新提交保留旧轮次，新轮次进入公共队列；任何重复、过时或转交后旧持有人的审核操作都会被拒绝。
- 站内通知保留当次结果；旧通知不再显示失效的“修改后重提”。通知入口 60 秒更新未读数。
- 浏览器草稿只保存答案，按用户、报名、天数、版本隔离；服务器确认提交成功后清除对应草稿。

## 运营指标

管理员访问 `/admin/operations`，可按训练营、批次、日期筛选并导出汇总 CSV。完成率只计算已批准报名、审核通过的课程。每日参与人数按用户去重，不将纯等待审核的用户计入当天有可做任务人数；同一人一天多次重提只计一人。

业务日期为北京时间，数据库时间戳为 UTC。任务超过 48 小时标记超时，不自动转交。worker 每五分钟扫描，并对接收人和提交轮次去重提醒；历史导入轮次不补发通知。扫描失败记录异常，下个周期重试，可用 `python worker.py --once` 检查任务和监控进程退出码。

每日参与采集由提交、审核、报名变更及 worker 驱动。历史日期仅在独立 worker 的全天采集覆盖完整时显示参与率（首个扫描需在 00:10 前，最后一次需在 23:50 后，中间间隔不超过十分钟）。今天为暂计；历史未采集、进程长时间中断的日期显示暂无数据。旧题目无法被真实恢复，迁移版本明确标为“历史导入版本”；原始提交时间保留，无法还原的开始时间保持空值。

审核耗时按提交轮次统计，中位数与 P90 使用所选日期内完成审核的轮次；当前积压、最长等待、待跟进和停留分布为实时状态。连续三天没有提交、且目前有可做任务的学员进入待跟进名单。该看板不读取答案正文，不作心理风险诊断。

## 测试

```powershell
python -m pip install -r requirements-dev.txt
python -m pytest tests.py test_regressions.py test_workflows.py test_migrations.py -q
node --test test_camp_content.js test_draft.js
```

真实浏览器验收使用独立临时数据库和本地 Web 服务，涵盖学员、审核员、管理员及桌面/手机宽度：

```powershell
python -m pip install -r requirements-browser.txt
# 默认使用已安装的 Microsoft Edge；也可以安装 Chromium。
# python -m playwright install chromium
# 使用 Chromium 时设置 BROWSER_CHANNEL=chromium。
$env:RUN_BROWSER_TESTS="1"
python -m pytest test_browser.py -v
```

可设置 `BROWSER_ARTIFACTS` 保存验收截图。测试账号和密码仅存在于临时测试数据库。发布前检查完整测试、浏览器流程、迁移预检、备份与 worker 运行情况。

## 初始超级管理员

首次启用审核员账号管理时，由具有服务器数据库访问权的维护人员执行 `python manage.py promote-super-admin --email 已存在的管理员邮箱`。命令只允许将现有管理员提升为超级管理员，不创建账号、不修改密码；普通管理员不能从网页自行提升权限。
